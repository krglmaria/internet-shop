## КОНТРАКТ (менять только по согласию обеих)
- Файлы: models.py, rbac.py, data.json, main.py, tests.py
- rbac.py экспортирует:
  - load_system(path="data.json") -> dict[str, User] (ключ = username; пароли из json хешируются SHA-256 при загрузке)
  - authenticate(users, username, password) -> User | None
  - check_access(user, permission_name: str) -> bool
- User: username, password_hash (SHA-256), roles (set[Role]), метод has_permission(name)
- Role: name, permissions (set[Permission])
- Permission: name, description
- data.json: {"permissions":[{"name","description"}], "roles":[{"name","permissions":[...]}], "users":[{"username","password","roles":[...]}]}
- Роли: Клиент, Менеджер по продажам, Контент-менеджер, Администратор
- Права: catalog:read (все), cart:manage (Клиент), orders:process (Менеджер, Админ), products:write (Контент-менеджер, Админ), users:ban (Админ)
- Тестовые пользователи: client, manager, content, admin, blogger (Клиент + Контент-менеджер); пароль = логин + "123"
